   HOW THE LOGIN WORKS
   -------------------
   The login page (shop-admin.html) reads credentials from

   shop-admin.html inside the ELVEN_ADMINS array, like:

     const ELVEN_ADMINS = [
       { user: 'admin1',     pass: 'elven@123' },
       { user: 'manager',    pass: 'elvenShop2026' },
       { user: 'superadmin', pass: 'Elven#Master99' },
     ];

   The admin panel reads this list on login. Only listed
   credentials will be accepted.
